Exercício prático envolvendo listas e dicionários  
Programa em python que recebe via input o nome, ano de nascimento e sexo do usuário. Armazenando os dados em um dicionário com listas  

Ao encerrar o cadastro são apresentados:  
-Total de cadastros efetuados;  
-A média de idades das pessoas   
-Lista de mulheres( se cadastradas) com menos de 30 anos   
-Lista de homens com idade acima da média
